# 烛生离线 HTML 原型改造设计

## 范围

本次只修改 `zhusheng-admin.html` 与 `zhusheng-sleep-figma.html`，保留纯 HTML/CSS/JavaScript 原型形态，不转换为微信小程序代码，不新增服务器依赖。两个 HTML 都必须可通过 `file://` 直接打开；图片、SVG 和视频只使用仓库内 `./image/` 相对路径。

## 目标

- 让后台设置与小程序体验遵循同一套已经确认的产品规则。
- 修复完成时间、奖励资格与次日揭晓混在一起的问题。
- 移除强制登录和提醒流程，让游客可直接进入体验。
- 为纯离线场景提供可靠的运营配置传递和用户数据备份。
- 保持现有视觉语言，修正流程、文案、可访问性和状态反馈，不重做品牌设计。

## 离线架构

### 后台配置

后台保存仍立即写入本地存储，并记录最后修改人和时间。所有保存入口同步更新一份统一配置对象。后台提供“导出运营配置”，生成带 schema 版本的 JSON 文件。

配置至少包含：基础文案、默认作息、仪式参数、按时容差、夜记与收藏文案、奖励规则、艺术作品池、隐私政策版本及更新时间。

### 小程序配置

小程序使用内置默认配置启动，不请求网络。设置页提供“导入运营配置”，用文件选择器与 `FileReader` 读取后台导出的 JSON。导入前校验 schema 版本和必填字段；失败时保留当前有效配置并显示错误。

由于两个独立 `file://` 页面无法可靠共享浏览器存储，JSON 文件是本次后台到小程序的唯一可靠配置传递方式，不伪装成实时 API。

### 本地数据

夜记、计划、完成记录、收藏、奖励次数和设置继续保存在本地。设置页提供本地备份导出和导入。导入前显示将覆盖的数据范围；原型采用二次确认，不自动上传文件。

## 小程序流程

### 首次使用

欢迎页直接进入三步引导，不再强制微信登录、头像、昵称或提醒授权。用户协议和隐私政策作为页面内可打开的对话框，并明确说明匿名统计事件与本地私人正文的边界。

### 仪式完成

用户进入晚安页时立即写入一条完成记录，保存计划时间、实际完成时间、是否在容差内、感恩与计划正文的本地引用。重复点击或刷新不得生成重复记录。

任何完成都会生成夜记。只有实际完成时间不晚于计划时间加 30 分钟时，记录才具有奖励资格并计入连续按时记录。

### 次日奖励

完成当晚只显示晚安和“明天查看收藏”，不能直接打开奖励。奖励在自然日变化后的首次打开时揭晓。

普通按时完成获得一次随机抽取。连续按时达到 3 晚和 7 晚时各增加一次抽取。随机允许重复；每幅作品记录获得次数与最近获得日期。无资格、未到次日或作品池为空时不得生成奖励。

### 收藏展示

收藏页同时展示“累计获得卡片数”和“不同作品数”。重复作品显示获得次数。删除固定的 `1 / 100` 语义和与规则不一致的预设锁定卡。

### 匿名统计

原型只在本地生成匿名事件队列，不发送网络请求。事件不得包含感恩、计划正文、昵称、头像或可反推正文的内容。隐私政策说明未来联网版本会在协议同意范围内上传事件。

## 后台调整

- 删除提醒配置、传统登录文案以及与游客模式冲突的字段。
- 保存成功提示改为“已立即生效于当前后台配置”，并显示最后修改人和时间。
- 艺术作品新增名称、艺术家、年代、缩略图路径、高清图路径、替代文本、公共领域来源和作品介绍字段。
- 作品只有全部必填字段通过校验、图片路径可解析且文章非空时，才标记为“奖励池可用”。
- 导出 CSV 必须基于当前艺术作品数据，不再使用写死的两行内容。
- 新增作品和编辑结果需要持久化，刷新后仍存在。
- 弹窗打开时聚焦首个字段、限制键盘焦点在弹窗内、关闭后恢复触发按钮焦点。

## 兼容性与错误处理

- 不使用 ES module、Service Worker 或启动时 `fetch()`，避免 `file://` 限制。
- 本地存储不可用时退化为当前会话内存，并显示“关闭页面后数据不会保留”。
- 资源路径统一为 `./image/...`；图片加载失败显示占位说明。
- JSON 或备份导入失败不得破坏已有数据。
- 时间计算覆盖跨午夜、凌晨完成和设备日期变化；所有奖励判断使用本地自然日。

## 自动化测试

在修改生产 HTML 前创建离线审查测试，并先确认旧实现失败。测试至少覆盖：

1. 两个 HTML 不引用 localhost、远程 URL、模块脚本或启动网络请求。
2. 所有本地图片、SVG 和视频引用都能在仓库中解析。
3. 小程序不再包含强制登录与提醒页面入口。
4. 完成记录、资格计算、次日揭晓、连续 3/7 晚加抽和重复计数通过固定时间用例。
5. 后台导出的配置可被小程序校验和应用。
6. 备份导入失败不会覆盖已有状态。
7. 艺术作品不完整时不能进入奖励池。
8. HTML 在 `file://` 下无未捕获异常，并在 390×844 与桌面尺寸下无水平溢出。

## 不在本次范围

- 微信小程序 WXML/WXSS/JavaScript 转换。
- 真实 API、数据库、管理员认证或匿名统计上传。
- 云端同步、加密云备份和跨设备恢复。
- 微信订阅消息。
